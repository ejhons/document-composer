# Doc Composer CLI

## Main commands

```cmd
dcp init --project_name "Projeto 1"
```

Cria sessão
```cmd
dcp start --session codigo-da-sessao
```

```cmd
dcp solve --forms
```

```cmd
dcp compile
```

```cmd
dcp recipe add "endereco-do-arquivo"
```

```cmd
dcp recipe remove "endereco-do-arquivo"
```

```cmd
dcp reset
```

```cmd
dcp variables
```


```cmd
dcp logout
```
